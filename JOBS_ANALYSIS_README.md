# Анализ вакансий с hh.ru - Документация

## 📋 Описание

Модуль для анализа вакансий с сайта hh.ru, который помогает студентам:
- Узнать, какие навыки наиболее востребованы на рынке
- Получить рекомендации по курсам на основе требований работодателей
- Увидеть статистику зарплат и требования к опыту
- Определить пробелы в навыках

## 🏗️ Архитектура

### Backend (`backend/src/jobs/`)

#### Модели (`models.py`)
- **JobVacancy** - хранение данных о вакансиях
- **JobAnalysis** - результаты анализа вакансий
- **MarketTrend** - тренды рынка труда

#### Сервисы
- **hh_parser.py** - парсинг API hh.ru
- **analyzer.py** - анализ вакансий и генерация рекомендаций

#### API Endpoints (`routing.py`)
- `POST /jobs/analyze` - анализ рынка по запросу
- `GET /jobs/trends/{language}` - тренды для языка
- `GET /jobs/skills/popular` - популярные навыки

### Frontend

#### Компоненты
- **MarketAnalysis.tsx** - страница с формой анализа и результатами
- **jobsApi.ts** - RTK Query API для работы с backend

## 🚀 Использование

### 1. Запуск backend

Убедитесь, что зависимости установлены:
```bash
cd backend
pip install -r requirements.txt
```

Запустите сервер:
```bash
cd src
uvicorn main:app --reload
```

### 2. Миграции БД

Модели автоматически создаются при первом запуске через `init_db()`.

Для ручного создания:
```python
from database import init_db
await init_db()
```

### 3. Использование API

#### Анализ рынка
```bash
curl -X POST "http://localhost:8000/jobs/analyze" \
  -H "Content-Type: application/json" \
  -H "Cookie: auth_token=..." \
  -d '{
    "query": "Python разработчик",
    "area": "1",
    "experience": "between1And3",
    "limit": 100
  }'
```

#### Получить популярные навыки
```bash
curl "http://localhost:8000/jobs/skills/popular?limit=10" \
  -H "Cookie: auth_token=..."
```

### 4. Frontend

Откройте страницу `/market-analysis` в приложении и:
1. Введите поисковый запрос (например, "Python разработчик")
2. Выберите регион (опционально)
3. Выберите уровень опыта (опционально)
4. Нажмите "Анализировать рынок"

## 🔧 Настройка

### Регионы hh.ru

Коды регионов можно найти в [документации hh.ru](https://api.hh.ru/areas):
- `1` - Москва
- `2` - Санкт-Петербург
- `113` - Россия

### Уровни опыта
- `noExperience` - Без опыта
- `between1And3` - 1-3 года
- `between3And6` - 3-6 лет
- `moreThan6` - Более 6 лет

## 🎯 Возможности расширения

1. **Кэширование результатов** - сохранять анализы в БД для быстрого доступа
2. **AI-рекомендации** - использовать GigaChat для более умных рекомендаций
3. **Исторические тренды** - отслеживать изменения спроса на навыки
4. **Персонализация** - учитывать прогресс студента при рекомендациях
5. **Уведомления** - оповещать о новых трендах в выбранных технологиях

## ⚠️ Ограничения

- hh.ru API имеет rate limits (рекомендуется не более 1 запроса в секунду)
- Парсинг навыков использует простой pattern matching (можно улучшить через NLP)
- Анализ выполняется в реальном времени (можно добавить кэширование)
