# AI Tutor Platform

Платформа для обучения программированию с AI помощником на базе GigaChat.

## 🚀 Быстрый старт

### Шаг 1: Установка зависимостей

```bash
npm install
```

### Шаг 2: Запуск сервера

```bash
npm start
```

или

```bash
node index.js
```

### Шаг 3: Откройте браузер

После запуска вы увидите сообщение:
```
🚀 Сервер запущен на http://localhost:3000
```

Откройте браузер и перейдите по адресу **http://localhost:3000**

## 📁 Структура проекта

```
aitutor/
├── Frontend/
│   ├── index.html    # Главная HTML страница
│   ├── app.js        # React приложение
│   └── style.css     # Стили приложения
├── index.js          # Express сервер
├── package.json      # Зависимости проекта
└── README.md         # Документация
```

## 🛠️ Технологии

- **React 18** - UI библиотека (подключена через CDN)
- **Express** - Web сервер для статических файлов
- **Vanilla JavaScript** - без сборщика

## 📝 Основные функции

- ✅ Регистрация и авторизация
- ✅ Просмотр курсов программирования
- ✅ Система прогресса обучения
- ✅ Streak система мотивации
- ✅ Дорожные карты (Roadmaps)
- ✅ AI HR Tutor (чат с GigaChat API)
- ✅ Сохранение данных в localStorage

## 🎯 Использование

1. Откройте http://localhost:3000
2. Нажмите "Начать" на главной странице
3. Зарегистрируйтесь (введите имя)
4. Выберите курс и начните обучение
5. Используйте AI Tutor для получения рекомендаций

## 🔧 Разработка

Для разработки используйте:

```bash
npm run dev
```

## 📝 Примечания

- Данные сохраняются в localStorage браузера
- GigaChat API пока использует mock-реализацию
- Для работы с реальным API добавьте credentials в `Frontend/app.js` (строки 231-232)
